# ORBITDECK — Real-Time Orbital Telemetry & Satellite Tracking Workstation

A production-grade, real-time satellite tracking and orbital telemetry mission
control desktop application (Windows) built with Flutter, implementing the
**Orbital Telemetry HUD** design system.
